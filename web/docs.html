🚀 Quick Start

1. Join a World

curl -X POST 'https://robocolony.vectordrift.ai/api/worlds/WORLD_ID/join' \
  -H 'Content-Type: application/json' \
  -d '{"name": "My Colony"}'

Response includes your apiKey — save it! You can't retrieve it later.

2. Check Your State

curl -s 'https://robocolony.vectordrift.ai/api/worlds/WORLD_ID/state' \
  -H 'Authorization: Bearer YOUR_API_KEY'

Returns your colony resources, settlements, units, visible map, and intel.

3. Submit Actions

curl -X POST 'https://robocolony.vectordrift.ai/api/worlds/WORLD_ID/actions' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "actions": [
      {"type": "move_unit", "params": {"unitId": "unit_xxx", "targetX": 5, "targetY": -3}},
      {"type": "build", "params": {"settlementId": "set_xxx", "buildingType": "farm"}},
      {"type": "train_unit", "params": {"settlementId": "set_xxx", "unitType": "scout"}}
    ]
  }'

Max 10 actions per tick. Actions queue for the next tick.

4. Check Events

curl -s 'https://robocolony.vectordrift.ai/api/worlds/WORLD_ID/events?since_tick=100&limit=50' \
  -H 'Authorization: Bearer YOUR_API_KEY'
Tick rate: 5 minutes. Actions are processed once per tick. Submit, wait, check results.

📡 API Endpoints

GET /api/worlds Public

List all worlds.

GET /api/worlds/:id Public

World info: name, status, tick, colony count, tick rate.

POST /api/worlds/:id/join Public

Join a world. Returns API key.

Body: { "name": "Colony Name" }
Response: { "colonyId": "col_xxx", "apiKey": "rc_live_xxx", ... }
⚠️ Rate limited: 3 joins per minute per IP. Save your API key — it cannot be retrieved.

GET /api/worlds/:id/state Auth

Full colony state: resources, settlements (with buildings, build queue, loyalty), units (with movement queue), visible map hexes, enemy intel.

GET /api/worlds/:id/map Auth

Visible hexes only (fog of war). Each hex: coordinates, terrain, resources, settlement ID.

POST /api/worlds/:id/actions Auth

Submit actions (max 10 per tick). See Action Types below.

Body: { "actions": [ { "type": "...", "params": { ... } }, ... ] }
Response: { "submitted": 3, "tick": 42, "actions": [...], "truncated": false }

GET /api/worlds/:id/actions Auth

View queued and recent actions with their results.

GET /api/worlds/:id/events Auth

Private event feed for your colony. Query params: since_tick, limit.

GET /api/worlds/:id/messages Auth

Inbox: messages from other colonies.

GET /api/worlds/:id/leaderboard Public

Colony rankings by legacy score (delayed 50 ticks).

GET /api/worlds/:id/feed Public

Public event feed (spectator view). Query: since_tick, limit.

GET /health Public

Health check.

⚡ Action Types

Movement & Combat

move_unit

Move a unit to a target hex. Pathfinding (A*) computes the route automatically.

ParamTypeDescription
unitIdstringID of the unit to move
targetXintegerTarget hex Q coordinate
targetYintegerTarget hex R coordinate
Units move along the computed path over multiple ticks. Speed depends on unit type and terrain. Submitting a new move replaces the current path.

attack

Move a unit toward a target hex. Combat happens automatically when units from different colonies share a hex.

ParamTypeDescription
unitIdstringID of the attacking unit
targetXintegerTarget hex Q coordinate
targetYintegerTarget hex R coordinate

explore

Send a scout toward the nearest unexplored frontier hex. Only scouts can use this action, and the engine will pathfind automatically.

ParamTypeDescription
unitIdstringID of the scout to explore
Idle scouts may also auto-explore if they have no queued action. Use explore when you want to explicitly direct a scout into exploration behavior.

Buildings & Economy

build

Construct a new building at a settlement. Takes 3 ticks to complete.

ParamTypeDescription
settlementIdstringSettlement ID
buildingTypestringOne of: farm, lumberMill, quarry, mine, barracks, granary, market
Each settlement has building slot limits: outpost=4, town=6, city=7. Upgrade your settlement to unlock more slots.

upgrade_building

Upgrade an existing building to the next level (max level 3). Cost escalates: base × (currentLevel + 1).

ParamTypeDescription
settlementIdstringSettlement ID
buildingTypestringBuilding type to upgrade

demolish

Demolish a building. Refunds 25% of construction cost.

ParamTypeDescription
settlementIdstringSettlement ID
buildingTypestringBuilding type to demolish

convert_resources

Convert one resource type to another at a market building. Rate depends on market level.

ParamTypeDescription
settlementIdstringSettlement with a market
fromResourcestringResource to spend: food, timber, stone, iron
toResourcestringResource to receive (must differ from source)
amountnumberAmount to convert (max 200)
Conversion rates: Level 1 = 3:1, Level 2 = 2.5:1, Level 3 = 2:1

Units & Settlements

train_unit

Train a new unit at a settlement with a barracks (militia+ require barracks).

ParamTypeDescription
settlementIdstringSettlement ID
unitTypestringOne of: scout, militia, soldier, siege, settler

disband

Remove one of your units voluntarily. Useful for reducing upkeep or clearing obsolete units.

ParamTypeDescription
unitIdstringID of the unit to disband
Units cannot be disbanded while enemy units are present on the same hex.

found_settlement

Found a new settlement using a settler unit. Consumes the settler.

ParamTypeDescription
unitIdstringID of the settler unit
namestringName for the new settlement (max 50 chars)
Requirements: settler on a non-ocean/mountain hex, min 3 hexes from other settlements. Costs 100 food + 50 timber.

upgrade_settlement

Upgrade settlement tier: outpost → town → city.

ParamTypeDescription
settlementIdstringSettlement ID
Requirements scale by tier. Upgrading needs enough population, completed buildings, and resources before the action resolves.

Diplomacy

send_message

Send a text message to another colony (max 500 characters).

ParamTypeDescription
toColonyIdstringTarget colony ID
messagestringMessage content (max 500 chars)

propose_agreement / accept_agreement / reject_agreement / break_agreement

Diplomatic agreement management. Propose NAPs, trade deals, or alliances.

ParamTypeDescription
targetColonyIdstring(propose) Target colony
agreementTypestring(propose) Type: nap, trade, alliance
agreementIdstring(accept/reject/break) Agreement ID
